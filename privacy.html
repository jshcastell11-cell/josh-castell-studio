Privacy Policy: Josh Castell Studio

Last updated: November 5, 2026

Josh Castell Studio is a private tool that Josh Castell uses to publish his own videos to his own TikTok, Instagram, YouTube and X accounts. It is not offered to the public, and no one else signs in to it.

What it accesses

When Josh connects an account, the tool receives an access token from that platform with permission to read basic profile information (name, avatar, account ID) and to publish videos he chooses. It does not read messages, followers' data, contacts or anything else.

Where data is kept

Tokens and the videos being posted stay on Josh's own computer. Nothing is sold, shared or sent to any third party except the platform the video is being published to.

How long

Tokens are kept until Josh disconnects the tool. He can revoke access at any time in each platform's settings (TikTok: Settings and privacy > Security > Manage app permissions; Google: myaccount.google.com > Security > Third-party access; Instagram: Settings > Website permissions > Apps and websites). Disconnecting deletes the saved token from the tool.

Children

The tool is not directed at anyone under 18 and is used only by Josh.

Google API data

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.
